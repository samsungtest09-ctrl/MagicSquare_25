## 3. GM-TC 시나리오 SSOT

| ID | name | 유형 | 기대 결과 |
|---|---|---|---|
| **GM-TC-01** | `normal_success` | small-first 성공 | `Output: [1,2,3,1,4,13]` |
| **GM-TC-02** | `reverse_success` | reverse fallback | `Output: [1,1,16,1,2,3]` |
| **GM-TC-03** | `invalid_blank_count` | Boundary 오류 | `Error: INVALID_BLANK_COUNT` |
| **GM-TC-04** | `duplicate_number` | Boundary 오류 | `Error: DUPLICATE_NUMBER` |
| **GM-TC-05** | `no_valid_magic_square` | Domain 오류 | `Error: NO_VALID_MAGIC_SQUARE` |

> GM-TC-01 격자는 small-first 전용 2빈칸 격자(`[[16,0,2,0],…]`)로 고정.  
> GM-TC-02는 reverse-only 격자(`[[0,0,2,13],…]`)로 고정.

## 4. Approve 패턴

| 조건 | 동작 |
|---|---|
| 기준 파일 **없음** | 현재 캡처 출력으로 자동 생성 |
| `GOLDEN_MASTER_APPROVE=1` | 기준 파일 **갱신** |
| 기준 파일 **있음** (기본) | `open(expected).read()` vs actual 비교 |
| **불일치** | `--- expected` / `+++ actual` unified diff 후 `AssertionError` |

```bash
# 기준 생성/갱신
python scripts/generate_golden_master.py

# 의도적 승인 (PowerShell)
$env:GOLDEN_MASTER_APPROVE=1
pytest -m golden_master -v
```
