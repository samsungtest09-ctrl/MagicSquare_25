# Magic Square 4x4 TDD Practice Report

## 문서 정보
- 프로젝트: Magic Square 4x4 TDD Practice
- 범위: Level 1 (Epic) ~ Level 5 (Scenario Verification and Summary)
- 목적: 불변식 기반 학습 설계의 일관성 검증 및 다음 단계 준비

---

## 1) Level 1 — Epic 정리

### Epic Title
- 불변식 기반 사고 훈련 시스템 구축

### 핵심 목표
- 4x4 Magic Square를 통해 불변식 중심 설계 사고를 훈련한다.
- Dual-Track UI + Logic TDD 흐름을 경험한다.
- 입력/출력 계약을 먼저 정의하고 리팩토링 후에도 외부 계약을 유지한다.

### 성공 기준(요약)
- Domain Logic 테스트 커버리지 95% 이상
- Boundary 입력 검증 계약 테스트 100% 통과
- 매직 넘버 금지 및 명명된 상수 사용 (`GRID_SIZE`, `MAX_VALUE`, `MAGIC_CONSTANT`)
- 정답 하드코딩 금지
- 주요 Invariant와 테스트 간 추적성 확보

---

## 2) Level 2 — User Journey 정리

### Journey Stage
1. Problem Recognition
2. Contract Definition
3. Domain Separation
4. Dual-Track TDD Progress
5. Regression Protection

### 핵심 연결성
- Stage 1~5는 문제 인식 → 계약 정의 → 책임 분리 → TDD 실행 → 회귀 보호의 학습 루프를 형성한다.
- Journey는 Epic의 불변식 중심 목표와 Dual-Track TDD 목표를 구조적으로 반영한다.

---

## 3) Level 3 — User Stories 정리

### Story 목록
- Story 1 (Boundary): 입력 검증
- Story 2 (Domain): 빈칸 좌표 탐색
- Story 3 (Domain): 누락 숫자 탐색
- Story 4 (Domain): 마방진 검증
- Story 5 (Domain + Boundary Output): 두 가지 조합 시도

### 특징
- Boundary Story와 Domain Story가 분리되어 있다.
- 각 Story마다 보호하는 Contract 또는 Invariant가 명시되어 있다.
- Acceptance Criteria가 테스트 가능한 문장으로 정리되어 있다.

---

## 4) Level 4 — Technical Scenario 정리

### 정의된 Scenario
- `SC-DOM-SOL-001`: small-first 실패 후 reverse 조합 성공
- `SC-BND-VAL-001`: 빈칸 개수 오류
- `SC-BND-VAL-002`: 0 제외 중복 값 오류
- `SC-BND-VAL-003`: 값 범위 오류

### 분해 준비 상태
- 각 Scenario에 RED Test ID Candidate 존재
- 각 Scenario에 Implementation Task Candidate 존재
