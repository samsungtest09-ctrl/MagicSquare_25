# Magic Square 4x4 TDD 프롬프트 설계 보고서

## 1. 목적
- Magic Square (4x4) TDD 설계 문서를 생성하기 위한 실행용 프롬프트를 정리한다.
- 구현 코드 작성 없이, 설계/계약/테스트/통합 중심의 결과물을 유도한다.

## 2. 산출물 범위
- 단일 실행형 프롬프트 1차안
- Dual-Track UI + Logic TDD 및 Clean Architecture 기준 강화 프롬프트 2차안
- 고정 출력 구조 및 검증 가능한 규칙 세트

## 3. 핵심 제약 반영 결과
- 구현 코드 금지
- 테스트 구현 코드 금지 (테스트 설계만 허용)
- UI를 화면이 아닌 Boundary로 정의
- Data Layer를 저장/로드 인터페이스 수준으로 제한
- 입력/출력 계약을 명시적으로 고정
- 모호한 표현 제거 및 테스트 가능 규칙 강제

## 4. 기대 효과
- 레이어 분리 훈련 강화
- 계약 기반 테스트 우선 설계 유도
- Red-Green-Refactor 루프를 문서 단계에서 명확히 계획
- 회귀 보호 및 추적성(Traceability) 확보
