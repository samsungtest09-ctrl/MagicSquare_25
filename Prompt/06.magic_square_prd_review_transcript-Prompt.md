# Prompt Transcript Export — PRD Review Session

본 문서는 Magic Square PRD 초안에 대한 검토 요청과 응답을 대화형 프롬프트 형태로 정리한 transcript이다.

---

## [T1] USER
방금 작성한 PRD를 검토하십시오.  
다음 기준으로 누락, 모순, 모호함을 찾아주세요.

1. 모든 FR에 테스트 가능한 AC가 있는가?  
2. 모든 AC가 Traceability Matrix에 연결되어 있는가?  
3. Boundary와 Domain 책임이 섞인 곳은 없는가?  
4. 오류 정책이 미정으로 남아 있지 않은가?  
5. small-first 성공과 reverse 성공 테스트 데이터가 구분되어 있는가?  
6. 1-index 좌표와 row-major 규칙이 누락되지 않았는가?  
7. 구현 코드나 테스트 코드가 포함되어 있지 않은가?

수정하지 말고 문제와 개선안만 보고하십시오.

## [T1] ASSISTANT (요약)
- 7개 기준으로 PRD를 점검하고 누락/모순/모호함을 보고함.
- 핵심 이슈:
  - AC-Traceability 연결 누락 1건 (`FR-02-AC-02`)
  - 오류 코드 체계 불일치 (`ERR-DESIGN-*` 정의 누락)
  - 실패 정책 외부 노출 방식 미확정
  - FR-05 레이어 책임 표기의 경계 모호성
- 충족 항목:
  - FR별 테스트 가능한 AC 존재
  - small-first/reverse 테스트 데이터 분리
  - 1-index/row-major 규칙 반영
  - 구현/테스트 코드 미포함
