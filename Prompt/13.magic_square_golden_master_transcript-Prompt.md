# Prompt Transcript Export — Golden Master 회귀 안전장치 (GM-1~GM-3) 세션

본 문서는 Magic_Square_XX 프로젝트의 **Golden Master 기준 파일 생성(GM-1)**, **회귀 테스트 코드(GM-2)**, **README To-Do 반영(GM-3)** 세션을 대화형 프롬프트 형태로 정리한 transcript이다.

---

## [T1] USER

**역할:** 회귀 테스트(Approval/Golden Master) 설계 전문가  
**환경:** pytest/JUnit/Catch2  
**태스크:** GM-1 — Magic Square Solver 출력 기반 Golden Master 기준 파일 생성

**구현 요구사항:**

1. **기준 출력 파일 생성 전략**
   - 입력 시나리오: 정상 조합 성공, reverse 조합 성공, invalid blank count, duplicate number, no valid solution
   - 출력 캡처: stdout capture 또는 Result DTO serialize
   - 생성 후: `git add tests/golden_master_expected.txt`

2. **approve 패턴**
   - 기준 파일 없으면: 현재 출력을 기준으로 자동 생성
   - 기준 파일 있으면: actual vs expected 비교
   - 불일치 시: unified diff 출력 후 FAIL

3. **기준 파일 구조 예시**
   ```text
   [normal_success]
   Input: ...
   Output: [3,3,1,4,4,6]
   [reverse_success] ...
   [invalid_blank_count] Error: INVALID_BLANK_COUNT
   ```

**산출물:** `tests/golden_master_expected.txt` + 생성 스크립트 + approve 패턴 설계 문서

1. 출력 캡처: stdout capture 또는 API result serialization

- GM-TC-04 DUPLICATE_NUMBER
- GM-TC-05 NO_VALID_MAGIC_SQUARE

**검증 대상:**
- int[6] 출력 형식, row-major, 1-index, small-first, reverse fallback, Error Contract

**산출물:** `test_golden_master_magic_square.*` + `golden_master_expected.txt` + 실행 결과 예시
