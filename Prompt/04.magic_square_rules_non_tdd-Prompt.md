# Prompt Transcript Export (Non-TDD)

본 문서는 현재 세션 대화 중 TDD 관련 질의/응답을 제외하고,
규칙 전환 및 아키텍처 설명 관련 프롬프트 흐름만 정리한 transcript이다.

---

## [T1] USER
`@.cursorrules`를 첨부 이미지 형태처럼 변경하고 싶다.
실행 방법을 알려달라. 구현/수정은 하지 말라.

## [T1] ASSISTANT
- `.cursorrules`를 `.cursor/rules/*.mdc` 구조로 마이그레이션하는 절차 제시
- 백업, 규칙 분해, frontmatter 구성, 검증, 레거시 비활성화 순서 안내

---

## [T2] USER
제안한 방법으로 수정을 진행해달라.

## [T2] ASSISTANT
- `.cursor/rules` 디렉터리 생성
- 규칙 주제별 `.mdc` 파일 5종 생성
- 기존 `.cursorrules` 백업 후 레거시 파일 비활성화(삭제)

---

## [T3] USER
`.mdc` 내용이 영어인데 영어여야 하는 이유가 있는지 질문.

## [T3] ASSISTANT
- 영어 필수 아님을 안내
- 본문은 한국어 가능, 기술 식별자/패턴은 원문 유지 권장

---

## [T4] USER
규칙 파일을 한국어로 바꿔달라.

## [T4] ASSISTANT
- 생성된 `.mdc` 5개 파일의 `description` 및 본문을 한국어로 통일
- `alwaysApply`, `globs`, 코드 식별자 등 동작 핵심 키는 유지

---

## [T5] USER
ECB 아키텍처를 쉽게 설명해달라.

## [T5] ASSISTANT
- `Boundary`, `Control`, `Entity` 역할과 책임 분리를 쉬운 비유로 설명
- 의존 방향 `Boundary -> Control -> Entity` 및 금지 방향 설명

---

## [T6] USER
현재 대화에서 TDD 관련 질문을 제외하고 프롬프트 저장/보고서 내보내기 요청.

## [T6] ASSISTANT
- Agent mode 전환 후 실제 파일 저장 진행
- 본 transcript와 대응 보고서를 `Prompt`/`Report` 폴더에 export
