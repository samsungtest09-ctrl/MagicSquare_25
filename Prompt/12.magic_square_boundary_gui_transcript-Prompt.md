# Prompt Transcript Export — Boundary GUI 구현·실행·GitHub 배포 세션

본 문서는 Magic_Square_XX 프로젝트의 **tkinter GUI 추가**, **GUI 실행**, **GitHub 업로드** 세션을 대화형 프롬프트 형태로 정리한 transcript이다.

---

## [T1] USER

GUI로 실행할 수 있게 만들어줘

## [T1] ASSISTANT (요약)

**레이어:** `boundary/gui` (ECB boundary — facade만 호출)

**신규 파일:**
- `run_gui.py` — 루트 실행 스크립트
- `src/boundary/gui/constants.py` — GUI 상수
- `src/boundary/gui/grid_input_parser.py` — 셀 텍스트 → 4×4 `int` 격자
- `src/boundary/gui/result_presenter.py` — facade 결과 메시지 포맷
- `src/boundary/gui/magic_square_app.py` — Tkinter 메인 앱
- `src/boundary/gui/__init__.py`, `__main__.py`
- `tests/boundary/test_gui_grid_parser.py` — 9건

**GUI 기능:**
- 4×4 격자 입력 (빈칸 = 비움 또는 0)
- 풀이 / 초기화 / 예제(G1) 불러오기
- 결과 패널 (오류 코드·메시지 또는 풀이 결과)

**아키텍처 준수:**
- `validate_and_solve()` facade만 호출
- `entity`/`control` 직접 import 금지
- `print()` 미사용, `logging` 사용
- tkinter 표준 라이브러리만 사용

**현재 제한:**
- `Solver.resolve()` 미구현 → 유효 4×4 입력 시 「풀이 기능은 아직 구현 중입니다」 표시
- 형상 오류 시 `[INVALID_SIZE] Grid must be 4x4.` 표시

**실행:**
```bash
python run_gui.py
# 또는
python -m boundary.gui
```
