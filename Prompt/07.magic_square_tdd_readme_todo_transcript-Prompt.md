- 필수 Scenario 15종 포함
- 출력 구조: Epic, User Stories, Tracking Board 표, RED Start Checklist, Traceability Summary

- 도메인 규칙 (4x4, 빈칸 2, 0/1~16, 합 34, int[6], 1-index, row-major, small-first/reverse)
